# reaper/scripts

Reaper extension scripts.

## Usage

To allow invoking the script from a keyboard shortcut:

1. Open the Action List dialog.
2. Select `New Action...` → `Load ReaScript...` and select the script
   from your filesystem.
3. Add a shortcut in the `Shortcuts for selected action` widget.
